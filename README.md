# User Management Dashboard

A responsive JavaScript-based User Management Dashboard built using HTML, CSS, and JavaScript. The project demonstrates CRUD operations using the Fetch API and a REST API.

## 🚀 Features

- Display users from an API
- Search users by name
- Add new users
- Update existing users
- Delete users
- Loading state
- Error handling
- Responsive user interface
- JavaScript ES Modules
- Async/Await and Promises
- Dynamic DOM rendering

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- REST API
- JSONPlaceholder

## 🔄 CRUD Operations

| Operation | HTTP Method |
|---|---|
| Fetch users | GET |
| Add user | POST |
| Update user | PATCH |
| Delete user | DELETE |

## ⚙️ How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using a local development server such as Live Server.
4. Use the dashboard to view, search, add, update, and delete users.

## 🌐 API

This project uses JSONPlaceholder as a fake REST API for practicing API requests and CRUD operations.
